## What to write

For each entry, in at most 80 words: what it would need to be true, and what it would break or cost. Then, in at most 60
words, the facts the choice turns on that a judge could check. State no preference and rank nothing: a note that leans
toward an entry makes the vote that reads it no longer blind.

Answer with the JSON object only: `status` `ok` (or `refused` with why in `reason`), `reason` an empty string otherwise,
and `note`, the note's text. Do not ask a question back, and do not run commands or read files.
