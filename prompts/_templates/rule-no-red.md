A fix has no possible red when no test can fail before it for the reason the finding names: a race between two reads, a read no test can observe, a static change. Its red is then empty and its `no_red` says why, naming the before-state it changed; the runner admits it in any cluster (a cluster with no test only when every group in it declares one) and records each reason as `declared-no-red`, for the follow-up review to judge. An empty red with no `no_red` is a skipped red, and its whole cluster is refused.
